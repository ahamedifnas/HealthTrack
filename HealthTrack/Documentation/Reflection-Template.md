# Personal reflection template

Complete this in your own words using examples you actually worked on. No personal experience or teamwork contribution has been fabricated here.

- **What I learned:** Which HealthTrack feature best demonstrates a new skill? Point to a controller/service and describe what you can now explain independently.
- **Challenges:** What failed during development? Record the symptoms, evidence and impact rather than only saying it was difficult.
- **How I solved issues:** Describe alternatives considered, the chosen fix and how you verified it. Which test or database query provided evidence?
- **ASP.NET MVC:** Explain one request from Razor form through model binding, validation, controller action and returned view/redirect. Why was a ViewModel helpful?
- **Entity Framework:** Explain a relationship, migration and LINQ query you worked on. How did you preserve existing data?
- **Security:** Describe the difference between authentication, role authorization and record ownership. Give a HealthTrack example for each.
- **Teamwork:** State your actual individual contributions and any real collaboration/review. If this was individual work, say so; do not invent a team.
- **Testing:** Which tests did you personally run? What was initially wrong, and what evidence supports the final result? Separate automated from manual checks.
- **Tradeoffs:** Why use request-triggered reminders? What happens when a user does not visit? Why use a separate deduplication ledger?
- **Future improvements:** Prioritize two or three feasible changes, such as background delivery, provider availability/duration, pagination or accessibility testing. Explain how you would verify them.

Suggested closing paragraph: what you would approach differently on a second attempt, with a concrete reason grounded in this project.
